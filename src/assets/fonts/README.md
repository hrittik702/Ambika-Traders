# INTERN Font Asset Directory

This directory holds the official **INTERN** web font files for Ambika Traders.

## Expected Files:
- `INTERN-Regular.woff2` (400)
- `INTERN-Regular.woff`
- `INTERN-Medium.woff2` (500)
- `INTERN-Medium.woff`
- `INTERN-SemiBold.woff2` (600)
- `INTERN-SemiBold.woff`
- `INTERN-Bold.woff2` (700)
- `INTERN-Bold.woff`

## Font Declaration:
The `@font-face` declarations are configured in `src/styles/index.css` and linked via the `var(--font-intern)` CSS variable token in `src/styles/tokens.css` and `tailwind.config.js`.

*Note: Per brand guidelines, no alternative commercial font (Inter, Poppins, Montserrat, Roboto, Geist, etc.) may be substituted as the design font.*
