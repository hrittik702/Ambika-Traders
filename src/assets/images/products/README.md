# Products Image Assets

Place client-supplied product images in this directory.
Naming convention:
- `aluminium-window-[variant].jpg`
- `sliding-partition-[variant].jpg`
- `sanitaryware-[variant].jpg`
- `modular-kitchen-[variant].jpg`
- `wardrobe-[variant].jpg`

Only use authentic client-supplied assets. Do not substitute with random stock images.
